Sistema de Compra e Venda de Ingressos

Este projeto é um sistema simples de compra e venda de ingressos desenvolvido em Python. Ele simula o gerenciamento de saldo de usuários e controle de estoque de ingressos, utilizando programação orientada a objetos (POO), com uso de classes, método __init__ e importação de módulos.

Funcionalidades

Cadastro de eventos com quantidade de ingressos (estoque)

Simulação de usuários com saldo disponível

Compra de ingressos com verificação de saldo e disponibilidade

Atualização automática de saldo e estoque após compra

Organização do código em múltiplos arquivos
